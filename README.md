# OwnClips

打遊戲時自動幫你錄影、標出精彩時刻的工具。所有影片都留在你自己的電腦上，不上傳雲端，也不用另外裝 OBS。

## 它能做什麼

- **自動錄影**：遊戲一開始就自動錄，結束自動停，你什麼都不用按。
- **標出擊殺**：Valorant 和英雄聯盟會自動找出你的擊殺、死亡和助攻，標在時間軸上，點一下就跳到那一刻。
- **精華片段**：每次擊殺自動變成一段精華，連殺會合併。想留下來的可以剪成獨立的影片檔。
- **錄任何東西**：按一個鍵就能錄任何視窗或整個螢幕。
- **內建播放器**：直接在 OwnClips 裡看錄影、看精華、剪片段。

## 支援哪些遊戲

| 遊戲 | 怎麼錄 | 擊殺標記 |
|---|---|---|
| Valorant | 每場對局錄成一支影片 | 有 |
| 英雄聯盟 | 每場對局錄成一支影片 | 有 |
| 其他遊戲 | 從開遊戲錄到關遊戲 | 沒有 |

Valorant 的靶場、新手教學，以及英雄聯盟的練習工具、新手教學、觀戰和重播不會錄。

## 安裝

你需要一台 Windows 10 或 Windows 11 的電腦，其他東西都包在安裝檔裡。

1. 到[下載頁面](https://github.com/7Jerrybf/ownclips/releases/tag/setup)下載 `OwnClips_x.x.x_x64-setup.exe`。
2. 雙擊執行。如果跳出藍色的「**Windows 已保護您的電腦**」，點「**其他資訊**」→「**仍要執行**」。這是因為程式是個人製作、沒有買微軟的簽章，不代表有病毒。
3. 一路按「**Next**」→「**Install**」→「**Finish**」。中途問「是否允許此 App 變更您的裝置？」，按「**是**」。

裝好後按 Windows 鍵，搜尋「**OwnClips**」打開。

## 開始使用

1. **讓 OwnClips 開著**。左下角顯示「**自動錄影待命**」就是準備好了。
2. **去打遊戲**。開始錄的時候，左下角會變成紅色的「錄影中」。
3. **打完回來看**。等十幾秒處理完，這場就會出現在「**對局**」分頁。

按右上角的 ✕ 只會把 OwnClips 縮到右下角的系統匣，它還在背景待命。想完全關掉，在系統匣圖示上按右鍵 →「結束 OwnClips」。

想要開機就自動啟動，到「設定 → 背景執行」打開「**開機自動啟動**」。

## 看錄影和精華

點「**對局**」分頁裡的任何一場：

- **時間軸**上綠色是擊殺、紅色是死亡、黃色是助攻，點一下就跳過去。
- **精華區間**清單列出每一段擊殺，點一下就播那段，按「**匯出**」存成影片檔。
- **自己剪一段**：拖時間軸上兩個金色把手設定開頭和結尾，再按剪刀。

剪出來的片段都在「**精華**」分頁，可以在那裡播放或刪除。

## 錄其他遊戲

Valorant 和英雄聯盟以外的遊戲，OwnClips 也會自動錄：

- 遊戲視窗在最前面超過 5 秒就開始錄。
- 關掉遊戲，或切到別的視窗超過 3 分鐘，就停止。
- 不想錄這次，按左下角的停止鈕，這次開的遊戲就不會再自動錄。

OwnClips 認得裝在 Steam、Epic、Xbox、GOG、Ubisoft、EA 裡的遊戲，以及用全螢幕執行的遊戲。如果認錯了：

- **遊戲沒被錄到**：先開著遊戲，到「設定 → 遊戲偵測 → 指定程式」按「新增…」，選那個遊戲，設成「**錄**」。
- **不是遊戲卻被錄了**：同一個地方新增那個程式，設成「**不錄**」。
- **完全不想自動錄其他遊戲**：把「自動錄其他遊戲」關掉。

## 手動錄影

想錄任何視窗或整個螢幕：

- 按左下角的「**錄影**」鍵，選一個螢幕或視窗就開始，再按一次停止。
- 或直接按快捷鍵 **Ctrl+Alt+F9**，會錄目前最前面的視窗，在全螢幕遊戲裡也能按，再按一次停止。快捷鍵可以在「設定 → 錄影快捷鍵」更改。

## 常用設定

都在「**設定**」分頁，改了會自動儲存。

- **聲音**：選「遊戲」只錄遊戲的聲音；選「系統」會把 Discord 語音、音樂等電腦所有聲音都錄進去。
- **麥克風**：打開就會把你講話的聲音一起錄進去。
- **解析度、FPS、畫質**：調低可以讓檔案變小。
- **位置**：錄影存在哪個資料夾，預設是「影片」裡的「OwnClips」。
- **容量上限**：打開後，錄影超過設定的大小時會自動刪掉最舊的。
- **擊殺前／擊殺後**：每段精華要包含擊殺前後幾秒。

## 常見問題

**錄影會佔多少空間？**
大約每小時 9 GB。一場 Valorant 競技約 5 GB。可以到設定打開「容量上限」讓它自動清掉最舊的錄影；想永久留下的對局，在「對局」分頁把滑鼠移到那一場上，按「保留」圖示，就不會被自動刪除。

**Valorant 沒有偵測到我的擊殺？**
預設位置是照 16:9 螢幕和預設遊戲介面設定的。如果你的螢幕比例不同或改過介面，要自己框一次：

1. 打開 Valorant，進到大廳。
2. OwnClips「設定 → 偵測」按「**擷取遊戲畫面**」。
3. 在截圖上用滑鼠框住右上角顯示擊殺訊息的地方，高度大約能放 5～6 行。
4. 按「**儲存區域**」。

英雄聯盟不需要這個設定。

**會不會被反作弊封號？**
OwnClips 不修改遊戲，也不讀取遊戲記憶體。它只是像 OBS 一樣錄下畫面和聲音，再用遊戲自己提供的資訊判斷對局開始和結束。

**對局打到一半才打開 OwnClips？**
Valorant 和英雄聯盟會馬上開始錄剩下的部分。

**怎麼更新？**
有新版本時左下角會出現「**有新版本**」，按「**更新並重新開啟**」就好，錄影和設定都會保留。錄影中不能更新，打完再按。

**怎麼解除安裝？**
Windows「設定 → 應用程式 → 已安裝的應用程式」找到 OwnClips，按「⋯ → 解除安裝」。錄影不會被刪掉，要清空的話自己刪除「影片\OwnClips」資料夾。
