# OwnClips

本機執行的 Valorant／英雄聯盟精華錄影工具，類似 Outplayed，但所有東西都留在你的電腦上，不上傳雲端，也不需要 OBS。

- **自動錄影**：對局開始時自動開錄，結束後自動停止
- **事件偵測**：自動找出你的擊殺、死亡和助攻，標記在整場時間軸上
- **精華區間**：每次擊殺自動標成一段精華，連殺會合併成多殺；直接從整場錄影播放，想要的話可以匯出成獨立影片
- **內建播放器**：在 app 裡看整場錄影，點時間軸上的標記直接跳到那一刻

# 安裝教學（一般使用者看這裡）

## 你需要準備什麼

- 一台 **Windows 10 或 Windows 11** 的電腦（就是平常打 Valorant 或英雄聯盟的那台）
- 硬碟要有空間放錄影：用預設畫質，**一場競技約 5 GB、一場死鬥約 1～2 GB**（大約每小時 9 GB）
- 安裝檔 `OwnClips_0.5.0_x64-setup.exe`（向分享給你的人索取）

其他東西都包在安裝檔裡，不用另外下載或安裝任何軟體。

## 步驟 1：執行安裝檔

1. 雙擊 `OwnClips_0.5.0_x64-setup.exe`。
2. Windows 可能會跳出藍色視窗「**Windows 已保護您的電腦**」。這是因為這個程式是個人製作的，沒有向微軟購買數位簽章，不代表有病毒。
   - 點視窗裡的「**其他資訊**」
   - 再點下面出現的「**仍要執行**」
3. 安裝畫面出現後，一路按「**Next**」（下一步）和「**Install**」（安裝），最後按「**Finish**」（完成）。
   - 不需要系統管理員權限，也不需要重新開機。

## 步驟 2：打開 OwnClips

- 按鍵盤的 Windows 鍵，打字搜尋「**OwnClips**」，點它打開。
- 打開後會看到左邊有「對局」、「精華」、「設定」三個分頁，左下角顯示「**待命中**」就代表準備好了。

## 步驟 3：去打一場

1. **讓 OwnClips 開著**（可以縮到工作列，但不要按右上角的 ✕ 關掉）。
2. 開 Valorant 或英雄聯盟正常打一場（英雄聯盟的練習工具、新手教學和觀戰／重播不會錄）。
3. 對局一開始，OwnClips 左下角會變成紅點的「**錄影中**」，還會顯示你這場的擊殺、死亡和助攻數。你什麼都不用按。
4. 對局結束後會自動停止錄影。等十幾秒到半分鐘處理完，這場就會出現在「**對局**」分頁。

> 靶場和新手教學不會錄影。

## 步驟 4：看精華

- **「精華」分頁**：列出所有對局的擊殺片段。滑鼠移到卡片上會預覽，點下去就播放。可以切換「只看多殺」。
- **「對局」分頁**：點一場對局，可以看完整錄影。
  - 時間軸上的**綠色**是擊殺、**紅色**是死亡、**黃色**是助攻，點了就跳到那一刻。
  - 下方的「精華區間」清單，點一下就播那一段。
  - 想把某一段存成影片檔分享給別人：按那一段旁邊的「**匯出**」，會自動打開存放的資料夾。

## 常見問題

**Q：打完一場，但沒有偵測到我的擊殺？**
（只有 Valorant 需要這樣做；英雄聯盟的擊殺是遊戲直接告訴 OwnClips 的，不用設定。）
OwnClips 預設的擊殺提示位置是照一般螢幕（16:9，例如 1920×1080、2560×1440）和預設遊戲介面設定的。如果你的螢幕比例不同，或改過遊戲的介面設定，需要自己框一次位置：

1. 先打開 Valorant，進到大廳就可以。
2. OwnClips →「設定」→ 往下找到「偵測」→ 按「**擷取遊戲畫面**」。
3. 在出現的遊戲截圖上，用滑鼠拖曳框住**畫面右上角顯示擊殺訊息的地方**。框高一點，大約能放 5～6 行擊殺訊息。
4. 按「**儲存區域**」。

**Q：錄影存在哪裡？**
預設在「**影片**」資料夾裡的「**OwnClips**」資料夾。可以在「設定 → 錄影位置」更改，或按旁邊的資料夾圖示直接打開。

**Q：硬碟快滿了怎麼辦？**
到「對局」分頁，在不要的對局上按垃圾桶圖示刪除（會移到資源回收筒）。也可以在「設定」把「畫質」調低，或把畫面更新率改成 30 FPS，檔案會變小。

**Q：錄影沒有聲音，或想錄到 Discord 語音、自己的麥克風？**
到「設定」的聲音選項：

- **只錄遊戲聲音**（預設）：只錄遊戲本身的聲音
- **系統所有聲音**：喇叭／耳機聽到的全部都錄，包含 Discord 和音樂
- **遊戲聲音＋麥克風**：遊戲聲音再加上你講話的聲音

**Q：會不會被 Vanguard（反作弊）封號？**
OwnClips 不會修改遊戲、不讀取遊戲記憶體，只是像 OBS 一樣錄下畫面和聲音，再讀遊戲自己寫在電腦裡的記錄檔來判斷對局開始和結束。

**Q：打開 OwnClips 時又開了第二次？**
沒關係，同時只會有一個 OwnClips 在執行，再開一次只會把原本的視窗叫到前面。

**Q：開機要自己打開嗎？**
目前要。記得打遊戲前先打開 OwnClips。如果在對局進行中才打開，它也會馬上開始錄剩下的部分。

**Q：有新版本時要怎麼更新？**
OwnClips 啟動時（之後每隔幾小時）會自動檢查。有新版本時左下角會出現「**有新版本**」，按「**更新並重新開啟**」就會自動下載、安裝並重新打開，錄影和設定都會保留。錄影中不能更新，打完那場再按就好。也可以到「設定 → 關於」按「**檢查更新**」。（0.5.0 以前的版本沒有這個功能，要手動裝一次新版安裝檔。）

## 解除安裝

Windows「設定」→「應用程式」→「已安裝的應用程式」→ 找到 **OwnClips** → 按「⋯」→「解除安裝」。

錄影檔不會被刪除，要清空的話，自己刪除「影片\OwnClips」資料夾即可。

# 開發者

## 運作方式

| 功能 | 做法 |
|---|---|
| 錄影 | ffmpeg 的 gfxcapture（Windows.Graphics.Capture）以螢幕原生速度擷取遊戲視窗，重新取樣成穩定的 60fps，交給顯卡硬體編碼（NVENC；沒有 NVIDIA 顯卡時改用 AMF／QSV／x264）。錄影中先寫成 MKV，當機也不會壞檔 |
| 聲音 | WASAPI 擷取，每個聲音封包依它的系統時間戳記放到正確位置（跟畫面擷取用同一個時鐘），對局結束後跟畫面對齊、合成 MP4，誤差約 ±10ms |
| 對局開始／結束 | 讀 Valorant 自己寫的記錄檔 `%LOCALAPPDATA%\VALORANT\Saved\Logs\ShooterGame*.log`，地圖和模式也從這裡取得 |
| 擊殺／死亡／助攻 | 看 killfeed 畫面：Valorant 會在你自己的頭像外框一圈黃線。黃框在左邊是你擊殺，在右邊是你死亡；隊友擊殺那一行最左邊的助攻小頭像有黃框，就是你的助攻 |
| 英雄聯盟 | 對局中遊戲本身會在本機開一個 Live Client Data API（`https://127.0.0.1:2999/liveclientdata/allgamedata`，Riot 官方提供給第三方工具用的，不需要金鑰也不連網路）。對局開始／結束、地圖、模式，以及每次擊殺的擊殺者、被擊殺者和助攻者都從這裡讀，不用看畫面，也不需要校準 |
| 精華與預覽 | 精華區間由擊殺時間即時計算；預覽直接用影片本身的畫面，不產生縮圖檔。匯出片段時 ffmpeg 直接複製串流，不重新編碼，很快且畫質無損 |

整個過程不讀寫遊戲記憶體、不注入程式，也不呼叫 Riot 的線上 API（英雄聯盟只讀遊戲自己在本機開的那個 API）。

## 開發需求

- 含 gfxcapture 濾鏡的新版 ffmpeg（winget 上的 Gyan 版本就有），開發時錄影和匯出片段都要用到；打包時也會從這裡複製進安裝檔：

  ```
  winget install Gyan.FFmpeg
  ```

- [Rust](https://rustup.rs)
- Node.js 18 以上

## 編譯與執行

```
cd app
npm install
npx tauri build --no-bundle
```

編譯好的程式在 `target\release\ownclips-app.exe`，也可以直接雙擊根目錄的 `OwnClips.bat`。

打包成安裝檔並發佈（產生 `target\release\bundle\nsis\OwnClips_<版本>_x64-setup.exe`，約 64 MB，上傳到 GitHub 的 `setup` Release）：

```
powershell -ExecutionPolicy Bypass -File app\scripts\release.ps1 -Notes "這版改了什麼"
```

腳本會問簽章私鑰的密碼，打包並簽章後上傳安裝檔、`.sig` 簽章檔和 `latest.json`，並刪掉 Release 上的舊版安裝檔。使用者的 app 會讀 `latest.json` 來發現新版本，並用 `tauri.conf.json` 裡的公鑰驗證安裝檔。私鑰放在 `%USERPROFILE%\.tauri\ownclips.key`，不進 git；**私鑰遺失的話，已安裝的使用者就收不到自動更新**，請另外備份。發佈前記得先升版本號（`app/package.json`、`app/package-lock.json`、`app/src-tauri/Cargo.toml`、`app/src-tauri/tauri.conf.json`），版本號沒變的話使用者不會收到更新。

打包前會自動執行 `app/scripts/fetch-ffmpeg.ps1`，把 winget 裝的 ffmpeg 複製到 `app/src-tauri/resources/ffmpeg/`（檔案太大，不放進 git）；電腦上沒有的話會先用 winget 安裝。安裝檔也內嵌了 WebView2 安裝程式，並設定為只安裝給目前使用者（不需要系統管理員權限）。

ffmpeg 是 GPL 授權，授權檔會一起放進安裝檔；公開散布安裝檔時，也要提供 ffmpeg 原始碼的取得方式（例如連到 https://www.gyan.dev/ffmpeg/builds/ ）。

開發模式（前端改了會即時更新）：

```
cd app
npx tauri dev
```

## 設定

| 項目 | 選項 | 預設 |
|---|---|---|
| 聲音 | 只錄遊戲聲音／系統所有聲音／遊戲聲音＋麥克風／不錄 | 只錄遊戲聲音 |
| 畫面更新率 | 30／60 FPS | 60 |
| 畫質 | 6～60 Mbps | 20 Mbps |
| 錄影位置 | 任意資料夾 | `影片\OwnClips` |
| 精華區間：擊殺前／後保留 | 2～20 秒／1～10 秒 | 8 秒／3 秒 |
| Killfeed 區域 | 在 app 裡框選 | 16:9、預設 HUD 的位置 |

設定存在 `%APPDATA%\OwnClips\config.json`，在 app 裡修改會自動儲存。

## 檔案結構

錄影資料夾裡的內容：

```
2026-10-21 19-29-38.mp4            整場錄影
2026-10-21 19-29-38.events.json    這場的地圖、模式和每個事件的時間點
clips\
  2026-10-21 19-29-38 05m10s 精選.mp4  手動匯出的片段（從對局第 5:10 開始）
```

## 命令列工具

不開 app 也能用：

```
cargo build --release -p ownclips

target\release\ownclips.exe detect                  自動錄影（等於 app 的背景功能）
target\release\ownclips.exe clip                    把所有錄影的擊殺片段批次裁成檔案（app 不會自動做）
target\release\ownclips.exe record 10 VALORANT game 錄任意視窗 10 秒，測試錄影器
```

`開始偵測.bat` 和 `裁切片段.bat` 分別對應 `detect` 和 `clip`。

## 專案結構

```

  audio.rs           聲音擷取與混音
  gamestate.rs       讀 Valorant 記錄檔，判斷對局開始／結束
  league.rs          讀英雄聯盟的本機 API：對局開始／結束和擊殺／死亡／助攻
  killfeed.rs        從 killfeed 畫面判斷擊殺／死亡／助攻
  session.rs         自動錄影流程，產生 .events.json
  clip.rs            用 ffmpeg 匯出片段
  capture.rs         視窗擷取
  config.rs          設定
  main.rs            命令列工具
app/                 Tauri 桌面 app
  src-tauri/         後端，提供給前端呼叫的指令

  scripts/           打包前準備 ffmpeg 的腳本
```

## 已知限制

- **對局結束後要等一下才看得到影片**：要先把畫面和聲音合成 MP4，36 分鐘的對局大約十幾秒到半分鐘。當機留下的錄影，下次開 app 時會自動合成救回。
- **助攻偵測的樣本還很少**：目前只用一場競技的 3 次助攻驗證過。偵測不到的黃色畫面會存到 `%APPDATA%\OwnClips\assist_samples\` 供之後調整。
- **偵測以 1440p 調校**：其他解析度理論上可以用（座標都用相對比例），但還沒實測過；非 16:9 的螢幕需要自己校準。
- **安裝檔沒有數位簽章**：安裝時 Windows 會跳出 SmartScreen 警告。
- **還沒做**：縮到系統匣常駐、開機自動啟動。
